# Roadmap

STEJECT turns an idea or a chat reply into a real GitHub repo, checks that it runs, and makes sure the student understands it. Every item below has to stay **free, serverless and private by default**.

## Shipped

| Version | Highlights |
|---|---|
| 1.0 | Paste a reply → checked manifest → real commits on GitHub. Update mode, resume, ship kit, Telegram, Learn mode. |
| 1.1 | Free cloud AI (Groq), start from an idea. |
| 1.2 | Plan → approve → write, change by chatting, self-check and fix loop (Python, web), live preview, understanding gate and mock interview, open a folder or a repo, starter gallery, pull request mode, repo polish pack, any OpenAI-style provider. |
| 1.3 | Checkpoints and undo push, safety checks before push, *Ship it for me*, real checks on the desktop (Node, Go, Java, C/C++, Python), in-browser AI (WebGPU, no key), issue → pull request, Repo doctor, classroom assignments with PROOF.md. |

## Next

- [ ] **Community starters**: load full reference projects from the separate `steject-starters` repo ([spec](docs/STARTERS-REPO.md)), with "open the finished example".
- [ ] **Images and binary files** in projects (icons, small assets).
- [ ] **Signed installers**, so Windows and macOS don't warn on first launch.
- [ ] **More languages in the browser check** (JavaScript tests without the desktop app).

## Later / ideas

- Teacher view that compares many students' PROOF.md over time.
- Offline bundle of the in-browser AI model on a USB stick for schools with slow internet.
- Translations of the UI.

## Won't do

- A STEJECT server, accounts, analytics or telemetry.
- Storing anyone's code or keys anywhere but their own computer and the services they choose.

Have an idea? Open a [feature request](https://github.com/aadvik7/Steject/issues/new/choose).
